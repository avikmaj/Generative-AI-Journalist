# Environment Prompts — World Design & Location Templates

## The Environment Is a Character

The world a film inhabits shapes everything — the colour palette, the lighting conditions, the sound world, the emotional register of every scene. Design environments before designing shots.

---

## Environment Lock Template

```
ENVIRONMENT: [Name/Location]
TYPE: [interior/exterior/hybrid]
ERA: [time period]
CLIMATE: [hot/cold/temperate/extreme]
TIME OF DAY: [specific — golden hour / midday / dusk / deep night / blue hour]
WEATHER: [clear/overcast/rain/fog/storm/snow]
ARCHITECTURE: [style, material, condition — pristine/ruined/aged/modern]
SURFACES: [ground material, wall material, ceiling if interior]
LIGHTING: [natural sources — sun direction, time; artificial sources — type, colour, position]
ATMOSPHERE: [particle quality — clean/dusty/smoky/foggy/misty]
COLOUR PALETTE: [dominant colours of this environment]
SOUND WORLD: [what does this place sound like?]
SCALE: [intimate/medium/vast — how big does this feel?]
CONDITION: [pristine/lived-in/aged/ruined/post-combat]
```

## Environment Templates by Genre

### Crime / Noir Urban Night

```
Rain-soaked city street, night, circa [era]. 
Slick black asphalt reflecting neon [colours] and sodium-orange streetlights. 
Low brick buildings, [condition]. Fire escapes casting ladder shadows.
Sparse foot traffic — the kind of night people avoid.
Ambient: distant traffic, rain on hard surfaces, a siren blocks away.
Colour: deep blacks, orange-amber street light, neon accent.
Atmosphere: urban wet, cold air visible as breath.
```

### War Zone / Battlefield

```
[Location, era], [time of day].
[Terrain: urban rubble / open field / jungle / desert / mountains].
[Condition: active combat / immediate aftermath / long-abandoned].
Environment: [crater field / blown-out structures / defensive positions / open ground].
Surfaces: [soil churned by vehicles / concrete rubble / mud / sand].
Atmosphere: [smoke from [source], dust airborne, [visibility level]].
Light: [overcast flat / harsh midday / golden hour] — [any fire sources providing additional light?].
Sound: [combat sounds / silence of aftermath / wind through ruins / distant fire].
Colour: desaturated, grey-green push, smoke haze, earth tones.
```

### Ancient / Historical

```
[Location], [specific historical period].
Architecture: [material — stone / timber / mud brick], [style — [culture-specific descriptors]].
Condition: [occupied and maintained / beginning to decay / centuries old but structurally intact].
Light: [era-appropriate sources — torches / fires / open courtyards / windows without glass].
Surfaces: [stone floor / packed earth / carved columns / decorated walls — describe specific details].
Scale: [intimate private space / public gathering space / monumental structure].
Colour: warm stone, fire amber, deep shadow where light doesn't reach.
Atmosphere: [dust / smoke / incense / outdoor air / animal presence].
```

### Science Fiction / Space

```
[Location type: space station / colony / alien world / post-Earth city].
Architecture: [functional industrial / sleek corporate / alien geometry / post-apocalyptic hybrid].
Materials: [metal and polymer / glass and neon / organic and grown / combination].
Light: [artificial — fluorescent cold / blue-white work lights / neon accent / bioluminescent].
Scale: [vast hangar scale / tight corridor / open habitat deck].
Views: [viewport to space / planet surface / orbital structure visible].
Atmosphere: [sterile and clean / industrial grime / alien particulate].
Colour: cold blue-white dominant, neon accent [colour], deep shadows.
Sound: ventilation hum, mechanical systems, distant announcements or alarms.
```

## Environment Continuity Lock

Once an environment is established, lock these for all subsequent shots in that location:

```
ENVIRONMENT CONTINUITY — [Location name]:
Time locked: [time of day at scene start — does not change unless story time passes]
Weather locked: [weather condition — does not change mid-scene]
Key light direction: [where the primary light comes from — holds for all shots]
Colour temperature: [K value or descriptor]
Ambient sound: [the continuous sound present in every shot]
Key props in fixed positions: [any environment elements that must stay consistent]
```
