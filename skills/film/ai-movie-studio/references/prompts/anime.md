# Anime Prompts — Style, Motion & Visual Language

## Anime Is a Distinct Visual Grammar

Anime is not a reduced or simplified version of live-action cinematography — it has its own developed visual grammar with specific conventions for emotion, motion, and timing. Apply these conventions deliberately.

---

## Core Anime Visual Conventions

### Emotional Expression Conventions

| Emotion | Anime visual shorthand |
|---|---|
| Surprise/shock | Large white circle in pupils, mouth open wide, freeze frame |
| Embarrassment | Blush marks on cheeks (parallel lines), steam from head |
| Extreme anger | Vein-pop on forehead, chibi reduction, exaggerated expression |
| Determination | Eyes narrow to sharp angle, light reflection reduced |
| Deep sadness | Eyes lose shine/reflection, shadows under eyes, slow tears |
| Love/admiration | Eyes become large sparkles, soft focus, colour saturation rises |

### Anime Motion Conventions

| Action | Anime treatment |
|---|---|
| High-speed movement | Speed lines radiating from point of movement |
| Impact | Freeze frame + flash frame, then motion resumes |
| Character entrance | Camera lingers on key detail then reveals full figure |
| Emotional peak | Time slows, camera pushes, music swells |
| Power release | Screen whites out then reveals aftermath |

## Anime Style Variants

### Shonen (Action/Youth)

```
STYLE: high-energy shonen anime aesthetic
Characters: [male lead: spiky or wild hair, determined expression, training physique]
Combat: [fast cuts, speed lines, impact frames, power-up sequences visible]
Colour: saturated, high contrast, dramatic lighting shifts in combat
Eyes: large, expressive, reflect determination and emotion
Lines: bold outlines, clean interior detail
Backgrounds: detailed during calm / impressionistic speed-lines in action
Camera: dynamic — low angles for power, dramatic perspective shifts
```

### Shojo (Romance/Character-Driven)

```
STYLE: shojo anime aesthetic
Characters: [elegant features, large detailed eyes, expressive hair, fashion-conscious]
Palette: soft, pastels, flower motifs, sparkles and light effects
Backgrounds: detailed and beautiful — architecture and nature rendered with care
Emotion: face close-ups, eye detail during emotional moments, flowers falling
Camera: gentle — slow orbits, soft focus on character features
```

### Seinen/Mature

```
STYLE: mature seinen anime aesthetic, [more realistic proportions / detailed]
Characters: [more realistic adult proportions, detailed expression, specific not generic]
Tone: [serious, complex, may be dark or introspective]
Colour: [may be more desaturated than shonen / rich colour for atmosphere]
Violence: [if applicable — visceral, consequence-visible, not cartoonish]
```

### Mecha / Sci-Fi Anime

```
STYLE: mecha anime aesthetic
Mecha design: [massive, mechanical, each panel and joint described]
Scale: [pilot cockpit interior vs exterior mech — the machine dwarfs the human]
Combat: [beam weapons / physical melee / missile barrages]
Environment: [space / ruined cityscape / battlefield]
Animation feel: [fluid mechanical movement, physics of mass and inertia]
```

## Anime Prompt Formula

```
[STYLE: specific anime aesthetic — shonen / shojo / seinen / mecha / ghibli / etc.]
[GRADE: anime colour science — [bright saturated / muted dramatic / warm soft]]
[CHARACTER: anime character description — face, eyes (large/specific), hair (colour and 
  style — detailed), wardrobe]
[ACTION: what they are doing — with anime-specific motion if applicable]
[ENVIRONMENT: background style — detailed realistic / impressionistic speed / 
  stylized flat color]
[CAMERA: anime cinematography — [dramatic perspective / character-centric / wide reveal]]
[EFFECTS: speed lines / impact frames / sakura petals / sparkles / power aura / etc.]
[TONE: emotional register of this specific frame]
```

## Studio Ghibli Style Reference

```
STYLE: Studio Ghibli aesthetic
Visual quality: hand-drawn warmth, organic colour, no hard digital edges
Characters: [realistic but slightly soft proportions, expressive faces, 
             clothing detailed and specific]
Backgrounds: [painterly, detailed, nature rendered with reverence — 
              every leaf and cloud is a character]
Motion: [weight and physics observable — Ghibli characters have mass]
Colour: [warm, natural, seasonal — the colour of the actual world, not enhanced]
Tone: [wonder, the weight of the ordinary world made sacred, 
       melancholy and hope coexisting]
Special elements: [wind, water, clouds given the same attention as characters]
```

---

## Golden Rule

> Anime is a visual language with its own grammar. Apply its conventions deliberately — speed lines mean speed, not decoration; impact frames mean significance, not random stylization.
