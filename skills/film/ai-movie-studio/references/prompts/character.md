# Character Prompts — Identity Design & Prompt Formulas

## The Character Prompt Is a Contract

A character prompt locks every visual detail that must remain consistent across every shot they appear in. Write it once. Apply it verbatim every time.

---

## Character Identity Token Template

```
CHARACTER: [Name]
AGE RANGE: [apparent age in years]
BUILD: [height description, body type — lean/athletic/heavy/slight]
FACE: [shape, key defining features, jawline, cheekbones, brow]
EYES: [colour, shape, expressiveness, default expression]
HAIR: [colour, length, texture, style — specific, not generic]
SKIN: [tone description, any marks — scars, tattoos, specific features]
WARDROBE: [every garment — material, colour, fit, specific details]
  Top: [garment type, colour, material]
  Bottom: [garment type, colour, material]
  Footwear: [type, colour]
  Accessories: [rings, watch, weapons, bags — each named]
MOVEMENT: [how they carry themselves — posture, gait, signature gestures]
VOICE: [register, tone quality, pace, accent — for dialogue shots]
```

## Character Archetypes — Prompt Formulas

### The Soldier / Warrior

```
[Gender, apparent age] soldier, [build — lean and hardened / powerful / wiry], 
[skin: weathered, tanned, possible scars from service], 
[hair: short, regulation cut / shaved], 
[eyes: alert and scanning, colour],
[wardrobe: combat fatigues — [colour/camo pattern], tactical vest [colour], 
  boots [colour], [any weapons or gear]],
posture upright and controlled, movement economical, nothing wasted
```

**Example:**
```
Male soldier, late 30s, lean and hardened — every extra ounce burned off years ago. 
Tanned weathered skin, a scar along the left jaw. Hair cropped close, dark brown. 
Eyes grey, always moving, assessing threats. Desert combat fatigues, olive-tan, 
tactical vest black, worn. Lace-up boots, brown leather. Rifle slung at right side. 
Posture perfect even at rest. Movement: quiet, deliberate, the walk of someone 
who has learned that noise kills.
```

---

### The Crime Detective / Investigator

```
[Gender, apparent age] detective, [build], 
[face: lived-in — the face of someone who has seen too much],
[hair: slightly neglected — this is not a person who prioritizes appearance],
[eyes: observant, tired but missing nothing, colour],
[wardrobe: [good suit that has seen better days — describe colour, fabric], 
  [tie if present — loosened], [coat if present], [shoes — describe]],
posture: slightly forward, always thinking, hands often in motion
```

### The Villain / Antagonist

```
[Gender, apparent age] — a figure that commands space without asking for it.
[Build: [specifics]], [face: [specific features that read as threat or intelligence]],
[hair: [immaculate / strategically disheveled depending on villain type]],
[eyes: colour, quality — flat and assessing / intensely engaged / cold],
[wardrobe: [quality — expensive materials, specific pieces, deliberate colour choice]],
stillness as a weapon — moves less than other people, occupies space with authority
```

### The Survivor / Refugee

```
[Gender, apparent age], the weight of what has happened visible in every line of them.
[Build: [signs of hardship — lean, possibly injured]],
[face: [exhaustion, vigilance that doesn't switch off]],
[eyes: colour — [deep, carrying things not spoken]],
[wardrobe: [practical, possibly damaged, layered for survival — specific items]],
movement: [efficient, never a wasted step — conserving everything]
```

## Character Groups — Multiple Character Prompt

When multiple characters appear in the same frame:

```
CHARACTERS IN FRAME:
A: [Full identity token — [Name], [brief key visual descriptors]]
B: [Full identity token — [Name], [brief key visual descriptors]]
RELATIONSHIP IN FRAME: [how they are positioned relative to each other]
FOCAL CHARACTER: [who is primary subject of this shot]
SECONDARY CHARACTER(S): [their role in the composition]
```

## Character Consistency Checklist

```
[ ] Identity token written in full
[ ] Token is verbatim from previous shots in this sequence
[ ] Wardrobe complete — no elements left to model inference
[ ] Physical build consistent with previous shots
[ ] Hair state consistent (or change justified by story time)
[ ] Any injuries from earlier in story are still present
[ ] Movement/posture description included
```

---

## Common Identity Failures and Prevention

| Failure | Prevention |
|---|---|
| Face drift between shots | Paste the full face description every clip — never summarize |
| Hair changes length | Specify exact length and style, not just color |
| Wardrobe color shift | Name specific colors with material (not "blue jacket" but "navy wool peacoat, double-breasted") |
| Build inconsistency | Keep build description identical — don't add synonyms or paraphrases |
| Scar/marking disappears | Name scars/marks in every clip block if character is visible |
