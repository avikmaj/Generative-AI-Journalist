# Horror Prompts — Fear, Dread & Psychological Terror

## Horror Is Dread, Not Shock

The most effective horror is not the jump scare — it is the sustained certainty that something is wrong before anything is seen. Design horror from the space before the reveal, not the reveal itself.

---

## The Horror Toolkit

| Technique | Effect |
|---|---|
| The wrong thing in ordinary space | A normal environment made threatening by something incorrect |
| What isn't seen | The threat implied by the audience's imagination |
| Wrong sound first | Audio cue before the visual — the brain fills in the worst possibility |
| The absent sound | Silence where sound should be — the world has noticed something the character hasn't |
| Slow revelation | Information given piece by piece — each piece worse than the last |
| False safety | Relief given and then removed — the second scare after the audience has exhaled |
| Proximity without agency | Threat is close; the character cannot act |

## Horror Scene Prompt Templates

### The Creeping Dread Scene

```
TONE: slow building dread — nothing has happened yet. That's the horror.
ENVIRONMENT: [ordinary location — bedroom / basement / corridor / house exterior at night]
LIGHTING: near-dark. Single [practical source — hallway light / phone screen / window ambient].
          Shadows occupy most of the frame.
CHARACTER: [alone, vulnerable, unaware of what the audience suspects]
CAMERA: [static hold] — the camera does not move. Stillness is the tension.
        [OR: very slow push-in — barely perceptible, but building]
AUDIO: [ambient — HVAC hum / house settling / distant street / rain]
       [then: a sound that doesn't belong. Brief. Stops.]
       [then: silence. The character heard it too.]
ACTION: [character processes the sound. Decides to [check / ignore / flee].]
        [The moment of decision. The audience knows the wrong choice.]
REVEAL STRATEGY: [do NOT reveal the threat. Hold on the character's face 
                  as they look toward the sound. Cut before they see.]
```

### The Monster / Entity Reveal

```
TONE: the transition from dread to terror — the thing is real.
REVEAL STRATEGY: [partial reveal first — a shape / a sound source located / a reflection].
                 [Hold the partial. Make the audience process it.]
                 [Then the full reveal — but framed to maximize impact: 
                  wrong angle / wrong light / wrong position relative to expected]
CHARACTER POSITION: [unaware of what we just saw / aware and unable to move / fleeing]
LIGHTING: [minimal — the thing should be partially obscured at all times].
          [Backlighting preferred — the SHAPE is terrifying, not the detail]
CAMERA: [static wide that makes the character small in the space / 
          handheld CU that denies the audience the geography / POV that puts us there]
AUDIO: [the sound it makes. Design this carefully — it should be wrong in a specific way.]
       [Then: silence immediately after.]
```

### Psychological Horror / Unreliable Reality

```
TONE: the character (and audience) cannot trust their perception.
TECHNIQUE: [environmental inconsistency — something changed position between shots /
             the character's memory doesn't match what we saw /
             the other person responds in a way that makes no sense]
CAMERA: [slightly off — framings that feel wrong by a few degrees /
          Dutch angle creeping in as reality deteriorates]
LIGHTING: [subtly wrong — light from no source / shadows going in wrong direction /
            colour temperature shifting when nothing should cause it to]
AUDIO: [echo that shouldn't be there / ambient that doesn't match the space /
         dialogue slightly out of sync with mouth]
ESCALATION: [each wrong thing is small. The horror is the accumulation.]
```

## The Jump Scare (Used Sparingly)

The jump scare is the cheapest tool in horror. It produces an autonomic startle reflex, not fear. Use it only when it is earned — when it arrives after genuine sustained dread.

**Structure of an effective jump scare:**
1. Sustained quiet / false resolution — audience has exhaled
2. Something draws attention to a specific spot
3. That spot holds for slightly too long
4. The arrival — fast, loud, filling the frame

```
JUMP SCARE PROMPT:
[Quiet scene established. Character safe.]
[A sound from [direction]. Character looks.]
[Hold on [specific spot]. Three beats. Four beats.]
[Entity / figure arrives — fills frame from [direction], audio spike, camera jolts]
[Immediate cut OR hold on character reaction — not on the entity]
```

## Horror Lighting Reference

| Setup | Effect |
|---|---|
| Single practical, failing | Vulnerability, the darkness always winning |
| Flashlight / torch | Narrow visibility — the audience sees only what the light finds |
| Underlighting | Classic monster-reveal — wrong shadow direction, unnatural face |
| Green-shifted ambient | Institutional evil, sickness, wrongness |
| No fill, deep shadow | Things living in the darkness of the frame |
| Lightning burst | Strobed reveal — seen fully for an instant, then gone |

## Horror Audio Design

```
HORROR AUDIO LAYER DESIGN:
  Foundation: [ambient that is slightly wrong — too quiet / wrong tone / inconsistent]
  Tension tool: [low-frequency tone building below hearing threshold — felt, not heard]
  Reveal sound: [the specific wrong sound — design what the entity sounds like]
  Impact: [the sudden audio spike at the scare moment]
  Aftermath: [immediate silence OR ringing / the absence of whatever was there before]
  Music: [minimal / none during peak tension — the score withdraws when the horror arrives]
```

## Genre-Specific Horror Subgenres

### Supernatural / Ghost

```
VISUAL SIGNATURE: [the ghost is not fully present — translucent / temporally offset / 
                    partially visible depending on light / existing in wrong physics]
BEHAVIOUR: [moves without following normal physics / appears in peripheral vision only /
             seen in mirrors or reflections but not directly / temperature drop as indicator]
```

### Creature Horror

```
VISUAL PRINCIPLE: [never show the whole creature clearly in the same shot as a character.
                    Show the part. Show the shadow. Show the aftermath. The full reveal 
                    comes only at the climax — and should be earned.]
```

### Psychological Horror

```
VISUAL PRINCIPLE: [the horror is in what the protagonist's perception shows us.
                    The audience doesn't know if it's real. Neither does the character.
                    Design the visual grammar of unreality: wrong detail / impossible 
                    continuity / the world slightly failing to cohere.]
```

---

## Golden Rule

> What the audience imagines is more frightening than anything you can show them. Design the conditions for their imagination to work. Then deny them the relief of seeing clearly.
