# Action Prompts — Combat, Chase & Intense Sequences

## Action Is Story Under Pressure

The purpose of an action sequence is not to show violence or spectacle — it is to reveal character under extreme pressure. Who someone is when survival is at stake is who they really are. Design action sequences around character revelation, not technical choreography.

---

## Action Scene Structure

Every action sequence needs:

```
1. STAKES ESTABLISHED     — What is being fought for? What is lost if they fail?
2. GEOGRAPHY CLEAR        — Where are we? Audience needs spatial orientation.
3. OPENING EXCHANGE       — Who has the advantage at the start?
4. ESCALATION             — Things get worse. Resources depleted. Options narrowing.
5. CRISIS MOMENT          — The character is losing. A choice must be made.
6. RESOLUTION             — Win, lose, or escape — but changed by what happened.
```

## Close-Quarters Combat (CQC) Prompt Template

```
EMOTIONAL TONE: [desperation / controlled aggression / survival / rage]
ENVIRONMENT: [tight interior / open ground / specific terrain], [time of day]
CHARACTER STATE: [physical condition — fresh / exhausted / injured / desperate]
COMBAT STYLE: [military CQC / street brawl / martial art / improvised / knife fight]
CAMERA: [handheld medium — chaos and immediacy / steady wide — choreography visible]
LIGHTING: [hard, practical sources only / available light / fire / emergency lighting]
ACTION:
  [Describe the sequence beat by beat — not technique, but intent and response]
  "[Character] forces [opponent] into [position] — [opponent] counters with [response] — 
   [escalation] — [the moment the fight turns] — [resolution of the exchange]"
AFTERMATH: [physical toll visible — breathing, blood, damage, posture]
AUDIO: [impact sounds / breathing / environment / score character]
```

## Ground Fight Prompt

```
Brutal close-quarters ground fight, [location — floor material, space available].
[Character A] forces [Character B] to the ground — the fight is about control now, 
not technique. [Character A physical state]. [Character B physical state].
Handheld camera, tight to the action, cutting on impact.
[Lighting — available and motivated source only].
Impacts sound correct — dull thud of body strikes, sharp crack of head impact, 
cloth strain and tear. Breathing ragged on both sides.
The fight is ugly. Neither person is winning cleanly.
```

## Gunfight Prompt Templates

### Urban Gunfight / Cover-Based

```
[Character(s)] taking fire in [urban environment].
Cover-based movement — [specific cover: cars / walls / doorframes / pillars].
Gunfire from [direction]: [weapon type — rifle / handgun / automatic].
[Character] moves between cover — exposed for [duration], then behind [next cover].
Muzzle flash [colour] at [position in frame]. Impacts — [material: concrete chips / glass / 
metal spark / wood splinter] — visible at hit locations.
Camera: [handheld tracking / tactical cutaway / POV dash-to-cover / wide establishing].
Audio: [gunfire type and echo for environment], brass cases [if applicable], 
distant shouts [if multiple combatants].
```

### Sniper Scene

```
[Setting — sniper hide location], [time of day, weather].
[Sniper] in position: prone, scope to eye, breathing controlled.
[Target] at [distance] in [environment].
Through scope: [target detail], crosshair centering.
Breathing cycle — hold —
The shot.
[Impact at target — [material response]].
[Immediate consequence — chaos, scatter, silence].
Audio: the snap of the shot, then the silence, then what follows.
Camera: scope POV / counter-shot from above hide / target perspective.
```

## Chase Sequence Prompt Template

```
CHASE TYPE: [foot / vehicle / mixed]
CHASING: [who is pursuing]
FLEEING: [who is fleeing, their physical state]
ENVIRONMENT: [where — urban / industrial / wilderness / interior / mixed]
OBSTACLES: [what makes this chase complex — [list specific obstacles]]

SEQUENCE:
Opening: [gap between pursuer and pursued — close / significant]
Escalation: [environment forcing decisions — obstacle 1, response; obstacle 2, response]
Crisis: [the gap is closing / the route is cut off / the character is failing]
Resolution: [escape achieved / capture / something changes the dynamic]

CAMERA: [tracking alongside / POV alternating / aerial overview / handheld close]
AUDIO: [breathing, footfall surface, ambient, score tempo matching chase pace]
```

## Vehicle Action — Car Chase

```
[Vehicle type(s)], [environment — urban / highway / mountain road / industrial].
[Initiating condition — pursuit beginning / crash starting / evasion sequence].

SEQUENCE:
[Vehicle A] forces [Vehicle B] toward [obstacle/direction].
[Vehicle B response — evasion, counter, obstacle navigation].
[Escalation — speed increase / weapon use / traffic / terrain hazard].
[Resolution beat — crash / escape / confrontation stop].

CAMERA: [tracking alongside / interior with exterior visible / drone overhead / 
         low angle on tires / wide establishing with vehicles small in environment].
PHYSICS: vehicle weight and inertia visible in every turn. Tires at limits of grip.
AUDIO: engine [type], tire squeal at traction limit, impact sounds, 
       [environmental sounds — rain / city / wind].
```

## Battle / War Scene Prompt

```
[Battle scale: small unit / company / full engagement].
[Historical/fictional context]. [Time of day, weather, terrain].

SETUP: [positions of opposing forces], [geography of the engagement space].
OPENING: [how the engagement begins — ambush / assault / defensive / artillery].
ESCALATION: [as casualties mount, positions shift, resources are consumed].
CHARACTER FOCUS: [one character we follow through the chaos].
VISUAL APPROACH: [wide establishing for scale / handheld medium for character / 
                  POV for immersion / aerial for tactical overview].

AUDIO DESIGN:
  Weapons: [specific to combatants and era]
  Environment: [terrain sounds under the battle]
  Human: [commands, cries, breathing]
  Score: [or absence of score — the sounds of battle as the music]

LIGHTING: [time of day, fire sources from burning [elements], muzzle flash illumination].
AFTERMATH NOTE: [battles end in exhaustion, not triumph. Design the silence after.]
```

## Action Scene Lighting Notes

| Time / Condition | Lighting for Action |
|---|---|
| Day exterior | Hard sun — high contrast, strong shadows, visibility full |
| Night exterior | Minimal ambient, key from [source], characters in and out of light |
| Interior day | Window sources only — motivated, directional |
| Underground/basement | Practical sources only — emergency lighting, flashlights, fire |
| Fire environment | Orange-red practical light, dancing shadows, smoke obscuring |

## The Aftermath Shot

Every action sequence ends in aftermath. Design this shot deliberately — it carries more weight than anything that preceded it.

```
AFTERMATH:
[Character] among the [result of the fight — bodies / wreckage / empty space].
[Physical state: injuries visible, breathing heavy, something broken in the posture].
[The emotional register — relief / horror / emptiness / determination].
[Camera: wide pull-back to show full scale / static hold / slow push-in on face].
[Audio: silence / distant fire / the sound of what remains].
[Duration: longer than comfortable. Let it breathe.]
```

---

## Golden Rule

> Violence in film is most powerful when it has weight and consequence. Design every action sequence to show what it costs — not just physically, but in what the character carries afterward.
