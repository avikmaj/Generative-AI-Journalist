## Prompt Approach

Kling prioritizes reference image identity. Lead with the reference image and use the text prompt to direct action and environment.

**Effective phrasing:**
- Reference image first (if available)
- Character identity described briefly (the image holds the detail)
- Action described simply and directly
- Environment described after character
- Camera noted as style rather than technical spec

---

## Kling Strengths
- Face consistency from reference image
- Expression and subtle performance quality
- Portrait and character-centric shots

## Example Prompt Structure

```
[Reference image] -> [Character in this environment] -> [Their action] -> 
[Environment description] -> [Camera/style in one sentence]
```
