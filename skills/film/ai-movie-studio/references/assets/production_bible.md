# Production Bible — Master Project Documentation

## The Production Bible Is the Film's Memory

The production bible is the single document that contains the state of the entire production. Every creative decision, every established visual rule, every character and location, every continuity constraint — all documented here. When a question arises, the bible answers it.

---

---

## Production Bible Workflow

1. **Create at project start** — before any prompts are written
2. **Update character and location sections** as bibles are completed
3. **Log every generation** with its continuity state
4. **Consult before every prompt** — especially after production gaps
5. **Version on major decisions** — creative direction changes get a new version

---

## Golden Rule

> The production bible exists so you never have to remember. It knows what every character is wearing in scene 4, what the lighting was in scene 2, and what the established rule is about the protagonist's scar. Consult it. Update it. Trust it.
