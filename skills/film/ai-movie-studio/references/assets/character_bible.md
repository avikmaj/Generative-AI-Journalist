# Character Bible — Complete Character Documentation System

## The Character Bible Is the Ground Truth

The character bible is the definitive document for every character in the production. It is consulted before writing any prompt that includes that character. It is updated when the character changes. It is never contradicted without a story reason.

---

## Character Bible Entry Template

```
=====================================================
CHARACTER BIBLE — [CHARACTER NAME]
Version: [1.0]
Last updated: [production stage]
=====================================================

## IDENTITY

Full name: [Name]
Also known as: [aliases / titles / what other characters call them]
Role in story: [protagonist / antagonist / supporting / ensemble]
Story function: [what narrative purpose does this character serve?]

## PHYSICAL IDENTITY

Age (apparent): [range]
Build: [height / body type / specific build descriptors]
Face: [shape, defining features — jaw, cheekbones, brow, nose, lips]
Eyes: [colour, shape, expressiveness, what they communicate]
Hair: [colour, length, texture, style — specific enough to reconstruct]
Skin: [tone, marks — scars, tattoos, birthmarks with location]
Voice: [register, tone, pace, accent, emotional register]

IDENTITY TOKEN STRING (paste verbatim in every prompt):
"[Complete description in one continuous paragraph that can be 
  copied into any generation prompt]"

## WARDROBE

### Primary Outfit (most common appearance)
Top: [specific garment, colour, material, fit, any details]
Bottom: [specific garment, colour, material]
Footwear: [type, colour, condition]
Outerwear: [coat/jacket if present — specific]
Accessories: [every item — ring location, watch, bag, weapon]

### Alternate Outfits (if applicable)
[List each alternate with the same specificity]

## PSYCHOLOGY

Core desire: [what does this character fundamentally want?]
Core fear: [what do they most fear?]
Internal flaw: [the false belief that drives their arc]
External goal: [what they consciously pursue in the story]
Internal need: [what they actually need, different from what they want]
Worldview: [how do they see other people / the world / themselves?]
Speech pattern: [how do they talk — vocabulary, cadence, what topics they avoid]

## CHARACTER ARC

Starting state: [who are they at the beginning?]
Arc type: [growth / fall / flat — from core/storytelling.md]
Arc trigger: [what event forces them to confront their flaw?]
Crisis choice: [the moment they must choose between the lie and the truth]
Ending state: [who are they at the end?]

## PERFORMANCE NOTES

Body language at rest: [posture, default stance, how they occupy space]
Under stress: [how their body language changes under pressure]
Signature gestures: [any recurring physical expression that is theirs]
Eye behavior: [default eye pattern — do they hold contact / avoid it / scan constantly?]
How they move: [deliberate / urgent / economical / expressive]

## RELATIONSHIPS

[Name A]: [relationship type and dynamic]
[Name B]: [relationship type and dynamic]

## CONTINUITY LOG

[Injuries or state changes acquired during the story:]
Scene X: [what happens, what is now different]

=====================================================
```

---

## Multiple Character Relationship Map

When multiple recurring characters are present, document their relationships:

```
RELATIONSHIP MAP:
[A] → [B]: [relationship type], [power dynamic], [emotional charge]
[A] → [C]: [relationship type], [dynamic]
[B] → [C]: [relationship type], [dynamic]

TRIANGLE NOTE: [if a three-way dynamic exists, what is the nature of it?]
```

---

## Character Group — Ensemble Management

For productions with large casts:

```
ENSEMBLE ROSTER:
  TIER 1 (full bible entry): [names — these characters need full documentation]
  TIER 2 (identity token only): [names — recurring but not arc-carrying]
  TIER 3 (type description): [one-off characters, described by type not individual]
```

---

## Golden Rule

> Write the character bible before the first prompt. Updating it mid-production is harder than building it right once. Every question about a character is answered here first.
