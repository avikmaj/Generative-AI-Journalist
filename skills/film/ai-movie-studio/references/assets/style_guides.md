# Style Guides — Visual Identity & Aesthetic Systems

## The Style Guide Defines the Film's Look

A style guide freezes the visual identity of the production into a document that every prompt consults. Without it, each clip can subtly drift toward different aesthetic choices until the film no longer looks like one cohesive work.

---

## Film Style Guide Template

```
=====================================================
VISUAL STYLE GUIDE — [FILM TITLE]
=====================================================

## CORE VISUAL IDENTITY

Visual style: [one-phrase description — e.g. "gritty photorealistic noir" / 
                "epic high-fantasy painterly" / "cold corporate thriller"]
Inspirations: [films whose visual language you're referencing — but not copying]

## COLOUR

Primary palette:
  Dominant colour: [the colour that appears most in the film]
  Secondary colour: [the second most present colour]
  Accent colour: [used sparingly for significance]
  Forbidden colours: [any colour that does not appear in this film]

Grade character:
  Highlights: [bright / controlled / blown / rich]
  Shadows: [deep and crushed / lifted and visible / neutral]
  Skin tone treatment: [warm / cool / desaturated / preserved]
  Saturation overall: [high / medium / low / selective]

LUT reference: [if a specific grade style is being emulated]

## LIGHT

Dominant light quality: [hard / soft / mixed]
Dominant colour temperature: [warm / cool / mixed — specific K range]
Shadow philosophy: [deep and dramatic / naturalistic / minimal]
Practicals: [are visible light sources present in most scenes?]
Atmosphere: [how much particulate — clean / dusty / foggy / smoky]

## CAMERA

Lens tendency: [wide / normal / long — what focal length characterizes this film]
Movement vocabulary: [favoured movements — slow / motivated / fluid / handheld]
Movements refused: [what this film never does with the camera]
Dominant shot size: [intimate CU-heavy / medium / wide and epic]
DOF philosophy: [shallow / deep / rack-focus driven]
Aspect ratio: [the crop that frames this world]

## EDITING RHYTHM

Pacing tendency: [slow and deliberate / medium / fast]
Cut type preference: [match cuts / hard cuts / fades / dissolves]
Scene length: [long scenes with few cuts / short punchy scenes]

## TYPOGRAPHY (for on-screen text)

Font family: [specific font or font character]
Colour: [text colour against film backgrounds]
Placement: [where text sits in frame]

## SOUND IDENTITY

Score tendency: [orchestral / electronic / minimal / hybrid]
Sound design philosophy: [realistic / heightened / stylized]
Mix character: [intimate and close / wide and epic / documentary flat]

## THE REFUSALS

Visual choices this film never makes:
[ ] [e.g. "No handheld in dialogue scenes"]
[ ] [e.g. "No unmotivated zoom"]
[ ] [e.g. "No bright warm grades in the villain's scenes"]

## RECOGNIZABILITY TEST

With the title removed, a viewer who has seen this film should be able to identify 
a new frame as belonging to it because:
[State the specific visual qualities that are this film's fingerprint]

=====================================================
```

---

## Style Reference Board (Per Scene)

For every scene, pull from the style guide and note which elements apply:

```
SCENE STYLE NOTE:
Grade: [from master style guide — confirm no drift]
Light quality: [from master style guide]
Camera approach: [from movement vocabulary]
Departed from guide: [if anything departs — state why and document it]
```

---

## Golden Rule

> A style guide is a series of constraints that create a visual identity. The more precisely the constraints are stated, the more coherent the film will look across all its clips.
