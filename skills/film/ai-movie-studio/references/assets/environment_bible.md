# Environment Bible — World Design & Location Documentation

## The Environment Bible Defines the Physical World

Every location that appears more than once needs a Bible entry. The environment bible ensures that a location looks the same whether it's visited in Act 1 or Act 3, whether it's night or morning, whether it's calm or under fire.

---

## Location Entry Template

```
=====================================================

Version: [1.0]
=====================================================

## IDENTITY

Location name: [what production calls this space]
Location type: [interior / exterior / hybrid]
Story function: [what narrative purpose does this location serve?]
First appearance: [what scene introduces this space]
Recurring: [yes / no — how many times does it appear?]

## PHYSICAL DESCRIPTION

Scale: [intimate / medium / vast — how much space is there?]
Architecture / terrain: [detailed description of the physical space]
Materials: [what surfaces exist — floor, walls, ceiling, ground]
Condition: [pristine / lived-in / aged / damaged / ruined]
Key props / features: [permanently installed elements that must match across visits]

## ENVIRONMENT TOKEN STRING (paste verbatim in location shots):
"[Complete location description for use in generation prompts]"

## LIGHTING CONDITIONS

### Standard lighting (default appearance)
Time of day: [most common time this location is visited]
Natural light: [sun direction if exterior / window positions if interior]
Artificial light: [all artificial sources — type, position, colour temperature]
Dominant colour temperature: [warm / cool / mixed]
Shadow quality: [hard / soft / minimal]
Atmosphere: [clean / dusty / smoky / foggy / misty]

### Alternate lighting conditions
[Night version:]
[Storm version:]
[Other conditions as applicable:]

Constant ambient: [what sound is always present here]

## COLOUR PALETTE

Dominant colours: [the colours that characterize this space]
```

## World Architecture — Multiple Locations

For productions with distinct world regions:

```
WORLD MAP (narrative):
REGION A: [name, character, what stories happen here]
  Key locations: [list]
  Visual signature: [distinct visual identity for this region]
  
REGION B: [name, character, what stories happen here]
  Key locations: [list]
  Visual signature: [distinct visual identity]

REGION CONTRAST NOTE: [how do the regions differ visually? 
                        The visual contrast between regions tells the story of the world.]
```

## Environment by Genre — Design Principles

| Genre | Environment design priority |
|---|---|
| Crime | Authenticity — real locations feel more dangerous than designed ones |
| Horror | Control of what is seen — the monster is the darkness, not the monster |
| Fantasy | Internal logic — every surface has a history that makes sense |
| Sci-Fi | Functional design — technology has a reason for existing |
| War | Scale and geography — the audience must understand the tactical situation |
| Drama | Detail that reveals character — this space says something about its inhabitants |

---

## Golden Rule

> A location that looks different across two scenes in the same film breaks the contract with the audience. Document every location before it appears, and consult the documentation before every subsequent visit.
