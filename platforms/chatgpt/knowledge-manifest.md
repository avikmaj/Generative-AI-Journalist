# Knowledge file manifest

ChatGPT Custom GPTs accept a limited number of knowledge files, so the build flattens the repo into a
small, well-named set. Names matter: the router in the system prompt references them literally.

Generated by `scripts/build_chatgpt_bundle.py` into `dist/chatgpt/`.

| File | Source | Purpose |
|---|---|---|
| `MODEL_CARD.md` | `model/MODEL_CARD.md` | Identity, rules, refusal policy |
| `SKILL_dv_<name>.md` | `skills/dv/<name>/SKILL.md` + its `references/` | One flattened file per DV skill |
| `SKILL_genai_<name>.md` | `skills/genai/<name>/SKILL.md` + its `references/` | One flattened file per GenAI skill |
| `PROMPTS.md` | `prompts/**` | Concatenated reusable task prompts |
| `OUTSKILL_CORPUS.md` | `knowledge/outskill/index.jsonl` | Normalised course notes with section anchors |
| `EVALS.md` | `evals/rubric.md` | Scoring rubric, so the GPT can self-check |

## Rules

- Flatten `references/` into the parent skill file under `## Reference: <filename>` headings.
  ChatGPT cannot resolve relative paths between knowledge files.
- Keep each file under ~2 MB and prefer Markdown over PDF; PDF extraction is lossy.
- Never upload anything from `knowledge/outskill/raw/`. Upload only the normalised, summarised
  `OUTSKILL_CORPUS.md`.
