# GitHub direct access

The repository is private. Use the already-connected GitHub connector for large reference corpora;
an unauthenticated raw URL correctly returns 404.

Keep skill bodies uploaded locally because they must be available on every turn. The limit-safe
bundles consolidate those bodies:

| Platform | Local uploads | Repository access |
|---|---:|---|
| Claude | 14 native Agent Skill zips; 0 markdown | Native GitHub project integration |
| ChatGPT | 5 markdown files | Connected GitHub for corpora |
| Grok | 5 markdown files | Connected GitHub for corpora |

The five ChatGPT/Grok files are `FAMILY_DV.md`, `FAMILY_GENAI.md`, `FAMILY_BUSINESS.md`,
`FAMILY_FILM.md`, and `CONTROL.md`. See [`11-setup-cards.md`](11-setup-cards.md) for exact setup.
